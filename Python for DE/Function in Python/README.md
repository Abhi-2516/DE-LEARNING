## ⚠️ Common Mistakes to Avoid

1. **Mutable default arguments**
   ```python
   ❌ def func(items=[]):      # Wrong!
   ✓ def func(items=None):    # Correct
   ```

2. **Forgetting return statement**
   ```python
   ❌ def calc(a, b):
       a + b              # Missing return!
   
   ✓ def calc(a, b):
       return a + b
   ```

3. **Modifying global state unintentionally**
   ```python
   ❌ def modify_list(items):
       items.append(5)    # Modifies original!
   
   ✓ def modify_list(items):
       new_items = items.copy()
       new_items.append(5)
       return new_items
   ```

4. **Wrong argument order**
   ```python
   ❌ def func(keyword=5, positional):  # Wrong!
   ✓ def func(positional, keyword=5):  # Correct
   ```

See **LEARNING_NOTES.md** for more pitfalls!
