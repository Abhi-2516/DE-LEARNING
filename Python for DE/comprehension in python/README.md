# Comprehensions in Python

This module teaches Python comprehensions as concise, readable ways to create collections from existing iterables. The examples use tea, recipes, sales, and inventory data.

## Learning Path

1. [01_list_comprehension.py](01_list_comprehension.py): create and filter lists
2. [02_set_comprehension.py](02_set_comprehension.py): collect unique values
3. [03_dictionary_comprehension.py](03_dictionary_comprehension.py): build key-value mappings
4. [04_generator_expression.py](04_generator_expression.py): calculate values lazily
5. [05_nested_comprehension.py](05_nested_comprehension.py): flatten and transform nested data
6. [06_smart_inventory_filter.py](06_smart_inventory_filter.py): combine all four styles in a project

## Run the Examples

From this directory:

```bash
python 01_list_comprehension.py
python 02_set_comprehension.py
python 03_dictionary_comprehension.py
python 04_generator_expression.py
python 05_nested_comprehension.py
python 06_smart_inventory_filter.py
```
